# Happy Birthday Riya ❤️

A complete romantic birthday website built with plain HTML, CSS and JavaScript.

## Project structure

```text
birthday-riya/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    │   ├── photo-1.jpg
    │   ├── photo-2.jpg
    │   ├── photo-3.jpg
    │   ├── photo-4.jpg
    │   ├── photo-5.jpg
    │   └── photo-6.jpg
    └── music/
        └── our-song.mp3
```

## 1. Add Riya's photos

Replace the six placeholder JPG files inside:

`assets/images/`

Keep these exact filenames:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`
- `photo-5.jpg`
- `photo-6.jpg`

You can use portrait, landscape or square photos. The website uses `object-fit: cover`, so they will be cropped nicely.

## 2. Add your song

Put your MP3 in:

`assets/music/our-song.mp3`

Then the "Play our song" button will play it.

Important: browsers normally prevent automatic audio playback. The visitor needs to tap the music button.

## 3. Personalize the relationship timeline

Open `index.html` and search for:

`THE BEGINNING`

`A FAVOURITE MEMORY`

`TODAY`

`THE FUTURE`

Replace the sample text with your actual dates and memories.

## 4. GitHub Pages

1. Create a GitHub repository.
2. Upload the files while preserving the folder structure.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Notes

The website has no backend and no build step. It is just HTML, CSS and JavaScript, so it works directly with GitHub Pages.
